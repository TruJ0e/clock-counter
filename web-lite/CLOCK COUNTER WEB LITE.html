CLOCK COUNTER

Colored space means time remains. As time runs out, that color disappears. Decorative dashes do not represent minutes.

+ Clock creates an independent timer. Resize the window to place clocks side by side. Each has its own duration, direction, color, alarm, and repeat setting.

Press Play to start a clock and automatically slide its bottom controls away. Use the small up arrow at the bottom to bring back Play/Pause, Reset and time adjustment; use the down arrow to tuck them away manually. Each clock has its own independent bottom drawer.

Use the gear on a clock to change its options. Set hours, minutes, and seconds below the dial. Changing a duration resets that clock only.

Start At: Set the timer duration, choose a local clock time in the bottom drawer, then press Set. For example, if it is 4:56 PM, choosing 5:00 PM starts automatically at 5:00. If that time has already passed today, it schedules tomorrow. The dial stays full until the start; use Cancel, Reset, or Play to stop waiting (Play starts immediately).

The Windows app must stay running (it may be hidden in the system tray). The website must remain open in a browser tab. A queued start is remembered across reloads only if its start time is still in the future.

Space: Start/pause selected clock
R: Reset selected clock
Ctrl+N: New clock
F: Fullscreen
H: Clock-only mode / restore controls
Escape: Restore controls or close menu/dialog

File → Timer contains start/pause, reset and timer settings. Clock-only mode shows only your selected clock, without toolbars, while its timer continues to run.

Clock settings are saved between launches. Active countdowns do not continue after the app has been closed.
